# Parallel Agents Protocol

<!-- Human-maintained. Claude reads only. -->

**Use multiple agents for:** 2+ independent tasks with no shared state (different files/domains/stages); a fresh perspective (adversarial review, independent validation); exploring several code areas at once.

**Don't when:** one task needs another's output (run sequentially); tasks modify the same file; a single-file change where spawn overhead outweighs the benefit; you are already a spawned agent (no nesting).
